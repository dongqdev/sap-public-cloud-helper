핵심 자동화 기능

S/4HANA 개발 과정에서 반복되는 작업을 줄여주는 5가지 도구입니다.

멀티 테넌트 원클릭 이동

시스템 구분(DEV, TEST, PROD)별 테넌트 번호와 별칭을 저장하고 Launchpad 홈으로 바로 이동합니다. OData 바인딩용 -api 엔드포인트도 원클릭으로 복사할 수 있습니다.

카탈로그 확장 게시 매크로

IAM 앱 ID 매핑 화면 이동, 쉼표로 구분된 비즈니스 카탈로그 역할 다중 탐색, 테이블 전체 선택 제어와 최종 게시(Publish) 확인 다이얼로그까지 자동으로 처리합니다.

주요 앱 바로가기

비즈니스 역할 유지보수, 사용자 정의 CDS 뷰 등 자주 쓰는 표준 관리 앱을 타일로 모아둡니다. Launchpad 검색 없이 바로 이동할 수 있습니다.

세션 쿠키 원클릭 리셋

테넌트 전환이나 계정 세션이 꼬였을 때, .s4hana.cloud.sap 등 매핑된 도메인의 브라우저 쿠키를 즉시 제거하고 새로고침하여 깨끗한 상태로 재로그인할 수 있게 합니다.

접속 계정 정보 바로보기

Fiori 상단 시스템 정보 바에 현재 로그인한 사용자 이름과 이메일을 함께 표시해 테넌트를 헷갈리지 않게 해줍니다. 옆의 ⓘ 아이콘을 클릭하면 SAP 표준 '정보(About)' 다이얼로그도 바로 열립니다.

상단 정보 바에 표시되는 접속 계정 이름·이메일 (예시 화면, 실제 계정 정보는 모자이크 처리)

설치 및 사용 방법

Chrome 개발자 모드로 1분 안에 로드할 수 있습니다.

1

프로젝트 다운로드

GitHub 저장소를 clone 하거나 Zip 파일을 내려받아 압축을 풉니다.

2

개발자 모드 켜기

주소창에 chrome://extensions를 입력하고 우측 상단의 '개발자 모드'를 켭니다.

3

압축해제된 확장 프로그램 로드

'압축해제된 확장 프로그램을 로드합니다'를 클릭하고 압축을 푼 폴더를 선택하면 끝입니다.
