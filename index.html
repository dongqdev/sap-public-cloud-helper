독보적인 4가지 핵심 자동화 기능

S/4HANA 개발 생산성을 몇 배로 높여줄 대표 자동화 도구 목록입니다.

🏢

멀티 테넌트 원클릭 점프

시스템 구분(DEV, TEST, PROD)별 테넌트 번호와 별칭을 저장하고 Launchpad 홈으로 1초 만에 점프합니다. OData 바인딩을 위한 -api 엔드포인트도 원클릭 복사할 수 있습니다.

⚡

카탈로그 확장 게시 매크로

IAM 앱 ID 매핑 화면 이동, 쉼표 구분 비즈니스 카탈로그 역할 다중 탐색, 테이블 '모두 선택' 체크박스 제어 및 최종 '게시(Publish)' 2차 확인 다이얼로그까지 완벽히 처리합니다.

📌

주요 앱 바로가기 관리

비즈니스 역할 유지보수, 사용자 정의 CDS 뷰 등 자주 사용하는 표준 관리 앱들을 타일 그리드로 제공합니다. 복잡한 Launchpad 검색 없이 원클릭으로 바로가기가 작동합니다.

🍪

세션 쿠키 원클릭 리셋

테넌트 스위칭이나 개발자 계정 세션 꼬임 시, 도메인(.s4hana.cloud.sap 등)과 매핑된 모든 로컬 브라우저 쿠키를 즉시 제거하고 새로고침하여 깨끗한 상태로 재로그인하도록 돕습니다.

확장 프로그램 등록 및 사용 방법

크롬 브라우저의 개발자 모드를 통해 3초 안에 로드가 완료됩니다.

1

프로젝트 다운로드 및 압축 해제

GitHub 소스 저장소에서 리포지토리를 clone 하거나 Zip 압축 패키지를 내려받아 압축을 풀어줍니다.

2

Chrome 개발자 모드 토글 켜기

브라우저 주소창에 chrome://extensions를 입력하고, 이동 후 우측 상단의 '개발자 모드' 스위치를 켭니다.

3

압축해제된 확장 프로그램 등록

'압축해제된 확장 프로그램을 로드합니다'를 클릭하고, 압축을 해제한 프로젝트 소스 폴더를 선택하면 끝납니다!
