개인정보처리방침

최종 업데이트: 2026-08-13 · SAP Public Cloud Helper는 SAP SE와 관계가 없는 비공식(unofficial) 개인 개발 도구입니다.

요약

  • 이 확장 프로그램은 어떠한 서버로도 데이터를 전송하지 않습니다. 자체 백엔드가 없습니다.
  • 등록한 테넌트 정보와 앱 바로가기는 브라우저(Chrome 계정)에만 저장됩니다.
  • 광고, 트래킹, 분석(Analytics) 스크립트를 포함하지 않습니다.
  • 어떠한 개인정보도 제3자에게 판매·공유하지 않습니다.

수집하는 정보와 저장 위치

이 확장 프로그램이 저장하는 정보는 사용자가 직접 입력한 다음 두 가지뿐입니다.

  • 테넌트 정보: 테넌트 번호, 별칭, 환경 구분(DEV/TEST/PROD)
  • 앱 바로가기 목록: 사용자가 등록한 Fiori 앱 경로

이 데이터는 Chrome의 chrome.storage.sync API에 저장됩니다. 즉, Chrome에 로그인되어 있고 동기화가 켜져 있다면 사용자 본인의 Google 계정을 통해 기기 간 동기화될 뿐, 개발자가 운영하는 서버로 전송되거나 개발자가 열람하는 일은 없습니다. Chrome 동기화가 꺼져 있다면 로컬 브라우저에만 저장됩니다.

쿠키(Cookies) 권한 사용 방식

팝업의 "쿠키 삭제" 버튼을 눌렀을 때만 동작합니다. 아래 도메인과 일치하는 쿠키만 조회·삭제 대상이 되며, 쿠키의 값(세션 토큰 등)을 읽거나 어디로도 전송하지 않고 즉시 삭제만 수행합니다.

  • *.s4hana.cloud.sap
  • *.oncnd.sap
  • *.sap.com
  • *.ondemand.com

호스트 권한(host_permissions) 사용 목적

위 4개 도메인 계열에 대한 접근 권한은 다음 두 기능에만 사용됩니다.

  • SAP Fiori 카탈로그 확장 게시 자동화 매크로를 실행하기 위한 콘텐츠 스크립트 주입 (s4hana.cloud.sap, oncnd.sap)
  • 사용자가 등록한 테넌트로 탭 이동, 그리고 위에 설명한 쿠키 삭제 기능의 도메인 범위 제한

이 외의 웹사이트에는 어떠한 방식으로도 접근하지 않습니다.
